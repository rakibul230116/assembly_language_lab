CSE 3210 - Microprocessor and Assembly Language Sessional: solutions to all 28 lab problems
Style follows Yu & Marut, "Assembly Language Programming and Organization of the IBM PC".

Book programs reused / adapted:
  PGM4_2  print string          -> P02, P07
  PGM4_3  case conversion       -> P08, P15
  PGM6_1  IBM character display -> P10
  PGM9_1  OUTDEC (signed output)-> used in many files
  PGM9_3  INDEC  (signed input) -> used in many files
  PGM17_2 recursive FACTORIAL   -> P26

Run in emu8086 (or MASM/TASM + DOS). Numbers entered through INDEC: -32768..32767, press Enter to finish.
P28 needs: Virtual Devices > LED Display opened before running.
